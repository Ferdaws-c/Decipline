# Decipline v1.0

Welcome to **Decipline**, a clean, robust, and completely self-contained desktop application designed for people who love to follow structured schedules and Pomodoro work cycles.

## 🤖 A Note on AI
This entire application, from the Python logic to the UI design, was programmed and developed by AI (specifically, Antigravity AI). It was crafted as a specialized tool to help organize daily tasks, focus blocks, and breaks seamlessly.

## 😅 The Name...
You might be wondering: *"Why is it spelled 'Decipline' instead of 'Discipline'?"* 
Well... let's just say "Discipline" was already taken (and maybe the AI had a little typo during the initial project scaffolding that we just leaned into!). Think of it as a unique brand name. 

## Features
- **Pomodoro Engine:** Native 25-minute focus cycles with automatic short and long breaks.
- **Task Management:** Import tasks via Excel, or add them manually through the intuitive UI.
- **State Persistence:** Your progress is saved locally. Close the app and come back right where you left off.
- **Telegram Notifications:** Get pinged on your phone when your breaks or free timers are over.

## Running the App
- **Standalone:** Just run `dist\Decipline.exe`. No Python installation required!
- **Source Code:** Run `python main.py` in the root directory if you'd like to tinker with the code.

Enjoy building your habits!
